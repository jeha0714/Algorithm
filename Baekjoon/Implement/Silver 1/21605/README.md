# 아름다운 수열

[백준 21605번](https://www.acmicpc.net/problem/21605)

## 문제

길이 $2N$인 수열 $A$의 아름다움 $b(A)$를 아래와 같이 정의합니다.

$$B_i = \begin{cases} 0, & \text{for } i = 0 \\ B_{i-1} \times A_{2i-1} + A_{2i} & \text{for } 1 \le i \le N \end{cases}$$

$$b(A) = B_N$$

아래 조건을 만족하는 수열 중 아름다움이 최대인 것을 출력합시다.

- 수열의 길이는 $2N$입니다.
- 수열의 원소 중 $N$개는 1, $N$개는 -1입니다.

## 입력

첫 줄에 $N$이 주어집니다.

## 출력

각 항을 띄어쓰기로 구분하여 아름다움이 최대인 수열을 출력합니다.

## 제한

- $1 \le N \le 10^5$

## 예제 입력 1

```
1
```

## 예제 출력 1

```
-1 1
```

위 수열의 아름다움은 $0 \times (-1) + 1 = 1$이고, 이것이 가능한 최대 아름다움입니다.
