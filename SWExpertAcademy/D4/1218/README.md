# [D4] [S/W 문제해결 기본] 4일차 - 괄호 짝짓기 - 1218

[문제 링크](https://swexpertacademy.com/main/code/problem/problemDetail.do?contestProbId=AV14e6BaALUCFAYD)

### 문제 설명

4종류의 괄호들 '()', '[]', '{}', '<>' 로 이루어진 문자열이 주어지면, 이 문자열이 유효한지 여부를 판별하는 프로그램을 작성하시오.

기호의 구성은 4가지 종류 '[' , ']', '(', ')', '{', '}', '<', '>' 가 총 8개이다.

문자열의 길이는 일정하지 않다.

### [입력]

각 테스트 케이스의 첫 번째 줄에는 테스트 케이스의 길이가 주어진다.

그 다음 줄에 테스트 케이스가 주어진다.

총 10개의 테스트 케이스가 주어진다.

### [출력]

#부호와 함께 테스트 케이스의 번호를 출력하고, 공백 문자 후 유효성 여부를 출력한다.

유효하면 1, 유효하지 않으면 0을 출력한다.

### [입출력 예시]

(입력의 일부)

```text
116
([](([]){}[])([]){}[])((()(({}[]{})){}[]{}[]{}[]{}[]{}[]{}[]{}[]{}[]{}[]{}[]{}[]{}[]{}[]{}[]{}[]{}[]{}[]{}[]{}[]{}[]{}))
218
({}[({({}[(({}{}){}[({})([{}])]))})][][])((({}[{}({}())]){}()(({}()(({})({})){})({}()({}()({}[]{}[]{}[]{}[]{}[]{}[]{}))))))
...
```

(출력의 일부)

```text
#1 1
#2 1
...
```
