## 📝 문제 : 선인장 숨기기

### 1. 문제 설명

m개의 행과 n개의 열로 구성된 격자가 주어지며, 이는 사막 지도를 나타냅니다. 격자의 좌상단 좌표는 `(0, 0)`, 우하단 좌표는 `(m-1, n-1)`입니다.

이 사막에 **가로 `w`, 세로 `h` 크기의 선인장 구역**을 조성하려고 합니다. 선인장 구역은 격자 축에 맞춘 연속된 `w × h` 크기의 부분 격자이며, **회전할 수 없습니다.**

비구름이 미리 정해진 순서(`drops`)대로 한 칸씩 빗방울을 뿌립니다. 선인장은 가능한 한 늦게 비를 맞아야 합니다.

**선택 우선순위**

1. 선인장이 **비를 아예 맞지 않는 위치**를 우선합니다.
2. 같은 조건이라면 **비가 가장 늦게 닿는 위치**를 고릅니다.
3. 그래도 같다면 **가장 위쪽(행 번호가 작은) 위치**를 고릅니다.
4. 마지막으로 **가장 왼쪽(열 번호가 작은) 위치**를 고릅니다.

격자의 크기 `m`, `n`, 선인장 구역의 크기 `h`, `w`, 비가 내리는 순서 `drops`가 매개변수로 주어질 때, 선인장 구역의 **좌상단 좌표** `[r, c]`를 return 하도록 `solution` 함수를 완성해 주세요.

---

### 2. 제한 사항

- 1 ≤ `m`, `n` ≤ 500,000
- 1 ≤ `m × n` ≤ 500,000
- 1 ≤ `h` ≤ `m`
- 1 ≤ `w` ≤ `n`
- 1 ≤ `drops`의 길이 ≤ `m × n`
- `drops[i]`는 `[r, c]` 형태이며, 0 ≤ `r` < `m`, 0 ≤ `c` < `n` 입니다.
- `drops`의 모든 원소는 서로 다른 칸의 좌표입니다.
