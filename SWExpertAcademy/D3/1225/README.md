## 문제 설명

다음 주어진 조건에 따라 8개의 숫자를 조작하여 암호를 생성한다.

- 8개의 숫자를 입력 받는다.
- 첫 번째 숫자를 1 감소시킨 뒤, 맨 뒤로 보낸다. 
- 다음 첫 번째 숫자는 2 감소시킨 뒤 맨 뒤로 보낸다. 
- 각각 3, 4, 5로 숫자를 바꾸어 가며 계속한다. 
- 이와 같은 과정을 한 사이클이라 한다.

8개의 숫자가 제자리로 돌아왔을 때, 1사이클이 종료된다.

단, 숫자가 감소할 때 0보다 작아지는 경우 0으로 유지되며, 프로그램은 종료된다. 이때의 8자리의 숫자 값이 암호가 된다.

## 제약 사항

주어지는 각 수는 integer 범위를 넘지 않는다.
마지막 암호 배열은 모두 한 자리 수로 구성되어 있다.

## 입력

총 10개의 테스트 케이스가 주어진다.

각 테스트 케이스의 첫 줄에는 테스트 케이스의 번호가 주어지고, 그 다음 줄에는 8개의 데이터가 주어진다.

## 출력

#부호와 함께 테스트 케이스의 번호를 출력하고, 공백 문자 후 테스트 케이스의 답을 출력한다.

## 입출력 예시

**입력**
```
1
9550 9556 9550 9553 9558 9551 9551 9551
...
```

**출력**
```
#1 6 2 2 9 4 1 3 0
...
```
