## 📝 문제 : 바탕화면 정리

### 1. 문제 설명

컴퓨터 바탕화면의 상태를 나타내는 문자열 배열 `wallpaper`가 주어집니다. 머쓱이는 최소한의 이동거리를 갖는 한 번의 드래그로 모든 파일을 선택해서 한 번에 삭제하려고 합니다.

* 바탕화면은 격자판이며, 각 격자점은 **(세로 좌표, 가로 좌표)**로 표현합니다.
* 빈칸은 **"."**, 파일이 있는 칸은 **"#"**입니다.
* 드래그는 시작점 $S(lux, luy)$에서 끝점 $E(rdx, rdy)$로 이동하는 행동입니다.
* **드래그 한 거리**: 
* 드래그 시 두 점을 각각 왼쪽 위, 오른쪽 아래로 하는 직사각형 내부의 모든 파일이 선택됩니다.

---

### 2. 드래그 범위의 정의

파일이 위치한 칸의 좌표가 $(i, j)$라면:

* 해당 칸을 포함하기 위한 최소 시작점은 ****입니다.
* 해당 칸을 포함하기 위한 최소 끝점은 ****입니다.

모든 파일을 포함하려면:

* ****: 파일이 있는 모든 칸의 세로 좌표 중 **최솟값**
* ****: 파일이 있는 모든 칸의 가로 좌표 중 **최솟값**
* ****: 파일이 있는 모든 칸의 세로 좌표 중 **최댓값 + 1**
* ****: 파일이 있는 모든 칸의 가로 좌표 중 **최댓값 + 1**

---

### 3. 제한사항

*  **`wallpaper`의 길이** 
*  **`wallpaper[i]`의 길이** 
* 모든 원소의 길이는 동일합니다.
* 바탕화면에는 적어도 하나의 파일이 있습니다.
* 드래그 시작점 $(lux, luy)$와 끝점 $(rdx, rdy)$는 를 만족해야 합니다.

---

### 4. 입출력 예

| wallpaper | result |
| --- | --- |
| [".#...", "..#..", "...#."] | [0, 1, 3, 4] |
| ["..........", ".....#....", "......##..", "...##.....", "....#....."] | [1, 3, 5, 8] |
| [".##...##.", "#..#.#..#", "#...#...#", ".#.....#.", "..#...#..", "...#.#...", "....#...."] | [0, 0, 7, 9] |
| ["..", "#."] | [1, 0, 2, 1] |

---

### 5. 입출력 예 설명

**입출력 예 #1**
(0, 1)에서 (3, 4)로 드래그하면 모든 파일을 선택할 수 있으며, 이때 거리 6이 최솟값입니다.

**입출력 예 #2**
파일들이 위치한 좌표들을 확인하여 세로의 최소/최대(+1), 가로의 최소/최대(+1)를 구하면 [1, 3, 5, 8]이 나옵니다.

**입출력 예 #4**
2행 1열(인덱스 기준 1행 0열)에만 아이콘이 있습니다.

* 세로 좌표: 1 하나뿐이므로 
* 가로 좌표: 0 하나뿐이므로 
* 따라서 결과는 **[1, 0, 2, 1]**입니다.
