## 📝 문제 : 숫자 짝꿍

### 1. 문제 설명

두 정수 의 임의의 자리에서 공통으로 나타나는 정수 $k(0 \le k \le 9)$들을 이용하여 만들 수 있는 가장 큰 정수를 두 수의 **짝꿍**이라 합니다.

* 단, 공통으로 나타나는 정수 중 서로 짝지을 수 있는 숫자만 사용합니다.
* 의 짝꿍이 존재하지 않으면, 짝꿍은 **"-1"**입니다.
* 의 짝꿍이 0으로만 구성되어 있다면, 짝꿍은 **"0"**입니다.

**진행 예시**

* ****
* 공통 숫자: 3, 0, 3
* 만들 수 있는 가장 큰 정수: **330**


* ****
* 공통 숫자: 2, 5, 5 (에 5가 3개, 에 5가 2개 있으므로 2개만 짝지을 수 있음)
* 만들 수 있는 가장 큰 정수: **552**



두 정수 가 주어졌을 때, 의 짝꿍을 return하는 `solution` 함수를 완성해 주세요.

---

### 2. 제한사항

* 3  **의 길이(자릿수)**  3,000,000입니다.
* 는 0으로 시작하지 않습니다.
* 의 짝꿍은 매우 큰 정수일 수 있으므로, **문자열**로 반환합니다.

---

### 3. 입출력 예

| X | Y | result |
| --- | --- | --- |
| "100" | "2345" | "-1" |
| "100" | "203045" | "0" |
| "100" | "123450" | "10" |
| "12321" | "42531" | "321" |
| "5525" | "1255" | "552" |

---

### 4. 입출력 예 설명

**입출력 예 #1**
의 공통된 숫자가 전혀 존재하지 않습니다. 따라서 **"-1"**을 return 합니다.

**입출력 예 #2**
의 공통된 숫자는 0으로만 구성되어 있습니다. 짝꿍은 정수 0이 되므로 **"0"**을 return 합니다.

**입출력 예 #3**
의 공통된 숫자는 1과 0입니다. 이를 조합해 만들 수 있는 가장 큰 정수인 **"10"**을 return 합니다.

**입출력 예 #4**
의 공통된 숫자는 3, 2, 1입니다. 가장 큰 정수인 **"321"**을 return 합니다.

**입출력 예 #5**
지문에 설명된 예시와 같습니다.
