# 1217. [S/W 문제해결 기본] 4일차 - 거듭 제곱

[문제 링크](https://swexpertacademy.com/main/code/problem/problemDetail.do?contestProbId=AV14t666AAwCFAYD)

### 문제 설명
다음과 같이 두 개의 숫자 N, M을 입력 받아 N의 M 거듭제곱 값을 구하는 프로그램을 작성하여라.

숫자 2와 5가 주어질 때,
2의 5거듭제곱은 2 X 2 X 2 X 2 X 2 = 32 이다.

숫자 3과 6이 주어질 때,
3의 6거듭제곱은 3 X 3 X 3 X 3 X 3 X 3 = 729 이다.

**[제약 사항]**

총 10개의 테스트 케이스가 주어진다.

결과 값은 Integer 범위를 넘어가지 않는다.

**[입력]**

각 테스트 케이스의 첫 줄에는 테스트 케이스의 번호가 주어지고 그 다음 줄에는 두 개의 숫자 N, M이 주어진다.

**[출력]**

#부호와 함께 테스트 케이스의 번호를 출력하고, 공백 문자 후 계산한 거듭 제곱의 값을 출력한다.
