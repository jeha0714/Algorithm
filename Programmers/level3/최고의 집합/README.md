## 📝 문제 : 최고의 집합

### 1. 문제 설명

자연수 개로 이루어진 중복 집합(multi set) 중에서 다음 두 조건을 만족하는 집합을 **최고의 집합**이라고 합니다.

1. 각 원소의 합이 \*\*\*\*가 되는 수의 집합
2. 위 조건을 만족하면서 **각 원소의 곱이 최대**가 되는 집합

**진행 예시**
자연수 2개()로 이루어진 집합 중 합이 9()가 되는 집합은 다음과 같습니다.

- { 1, 8 } → 곱: 8
- { 2, 7 } → 곱: 14
- { 3, 6 } → 곱: 18
- **{ 4, 5 } → 곱: 20** (최고의 집합)

집합의 원소의 개수 \***\*과 모든 원소들의 합 \*\***가 매개변수로 주어질 때, 최고의 집합을 return 하는 `solution` 함수를 완성해 주세요.

---

### 2. 제한사항

- 최고의 집합은 **오름차순으로 정렬된** 1차원 배열(list, vector)로 return 합니다.
- 만약 최고의 집합이 존재하지 않는 경우(자연수 개로 합 를 만들 수 없는 경우), 크기가 1인 배열에 **-1**을 채워서 return 합니다.
- 자연수의 개수 \*\*\*\*: 1 이상 10,000 이하
- 모든 원소들의 합 \*\*\*\*: 1 이상 100,000,000 이하

---

### 3. 입출력 예

| n   | s   | result |
| --- | --- | ------ |
| 2   | 9   | [4, 5] |
| 2   | 1   | [-1]   |
| 2   | 8   | [4, 4] |

---

### 4. 입출력 예 설명

**입출력 예 #1**
문제의 예시와 같습니다. 합이 9이면서 곱이 최대가 되는 {4, 5}를 오름차순으로 반환합니다.

**입출력 예 #2**
자연수 2개를 더해서 합이 1이 되는 집합은 존재하지 않습니다. (자연수는 1부터 시작하므로 최소 합은 2입니다.) 따라서 **[-1]**을 반환합니다.

**입출력 예 #3**
자연수 2개로 이루어진 합이 8인 집합들 중 곱이 최대인 것은 {4, 4}입니다.
